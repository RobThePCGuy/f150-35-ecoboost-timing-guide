# Specifications and torque log

Torque, angle and sealing values from the Ford workshop procedures for the 2011–2014 F-150 3.5L EcoBoost. Ford units first. Keep the Ford procedure open for positions and sequences.

**Nm, lb-in and lb-ft are different units.** Values below preserve Ford's printed units. A torque-angle instruction does not automatically mean the bolt must be replaced: the replacement column records explicit instructions. Where the source does not give a special thread treatment, follow the complete operation; do not add oil, anti-seize or threadlocker by habit. Read source conflicts, especially the fuel flare nut and timing callout.

## Mechanical setup and checks

- **Starting setup:** turn crankshaft **clockwise**, align intake VCT marks exactly as the removal illustration shows; install 303-1248 tools on LH/RH cam flats (Ford identifies this as TDC). Do not substitute a clock-face guess for the saved figure.
- **Secondary chains:** match colored links to each phaser's marks and fit cam dowels. Use the new-secondary-tensioner branch for replacement tensioners. 303-1530 retains installed tensioners where the specified branch uses it. Follow each bank's full order and activation step.
- **Crank sprocket:** timing dot faces out. Primary colored links align with intake VCT marks and crank sprocket; crank mark lies between its two colored links.
- **Post-check:** **48 links between RH intake colored link (1) and LH intake colored link (2); 35 links between LH link (2) and the two crank links (3)**. Ford N0122131 figure. The Oil Pump text has an RH/LH typo; see source-conflict notes.
- **Rotation:** Timing Drive Components states this mark/link post-check; it does not state a universal two-turn validation. The A/C belt installation separately requires one full clockwise revolution to check belt seating. Fuel-pump installation separately requires clockwise crank rotation to put its cam at BDC. Finish the timing post-check before those subsequent rotations, with fixtures removed as prescribed. Stop for unexplained resistance.
- **Counter-holding:** the pulley procedure uses a strap wrench. Do not infer that every positioning tool can resist every fastener torque; follow the actual operation and supplied tool instructions.
